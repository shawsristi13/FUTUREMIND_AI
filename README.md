## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/shawsristi13/FUTUREMIND_AI.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
